Try it

  1. Android or desktop Chrome: an install banner appears at the bottom. Accept it and this panel flips to standalone.
  2. iPhone or iPad: the banner tells you to tap Share, then Add to Home Screen, because iOS offers no install API.
  3. Offline: load the page once, turn off the network, reload. The service worker serves it from cache.
  4. Then look in the backoffice: Settings, then the PWA dashboard, and your visit is counted.
